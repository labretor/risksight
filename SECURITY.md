# Security Policy

## Scope

This repository is a public case study. It contains documentation and a static showcase website only.

It does **not** contain:

- production credentials, API keys, tokens or secrets of any kind
- confidential, proprietary or real operational datasets
- real entity or customer identifiers
- internal company information, systems, URLs or file names
- the RiskSight application itself

All figures, identifiers and screenshots in this repository come from a synthetic dataset generated for demonstration.

## The showcase website

The website in `public/` is static. It makes no network requests, loads no third-party scripts, fonts or analytics, sets no cookies and collects no data.

## Reporting a concern

If you believe something in this repository should not be public, or you find a security issue in the static site, please open a GitHub issue that describes the location of the concern without repeating the sensitive content, or use GitHub's private vulnerability reporting for this repository if it is enabled.

The author will review reports and remove or correct material where appropriate.
