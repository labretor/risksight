# Demonstration data

The screenshots and the showcase website in this repository were produced from a **synthetic dataset generated for demonstration**.

- Entity identifiers follow the pattern `DEMO-001` to `DEMO-120` and refer to no real person, business or account.
- Values, amounts and distributions are artificial.
- Some interface labels in the images were generalised so that nothing in them depends on any particular organization.
- No real export, report or dataset from any organization was used or is included.

The demonstration files themselves are intentionally not included in this repository. The case study documents the idea and the outcomes, not a reusable dataset.
